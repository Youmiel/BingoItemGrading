# 动作前缀的计数口径

> 由 `bg kinds --out docs/data/action-kinds.md` 生成，不要手改。

`discrete` 决定「凑 N 件」怎么计次：**离散**按 `ceil(N / 单次产出)`；
**可分割**按 `N / 单次产出`。单次产出恰为 1 时两者同值，语义仍要分清。

共 47 个前缀：离散 40 个，可分割 7 个。

| 前缀 | 计数口径 | 理由 |
|---|---|---|
| `mine:` | 可分割 | 挖方块按块线性：挖 N 块就是 N 块的时间。 |
| `loot:` | 离散 | 跑一趟结构开箱：一趟里开几个箱是固定的，不能只跑半趟。 |
| `loot_block:` | 离散 | 挖掉一整块结构方块才拿到掉落物（雪块 4 个雪球、一次最多 28 件），不能挖半块。 |
| `brush:` | 离散 | 刷一块可疑方块是一次动作，产出按次结算（陶片 1 件/块）。 |
| `dig:` | 离散 | 嗅探兽刨一次地有固定冷却（8 分钟），不能刨半次。 |
| `harvest:` | 离散 | 打一次 creaking heart 的守护者才掉树脂，事件不可分割。 |
| `sniffer:` | 离散 | 孵化嗅探兽蛋并养到成年是一次事件。 |
| `plant:` | 离散 | 种一株作物是一次动作。 |
| `grow:` | 离散 | 等海龟长成一次。 |
| `bloom:` | 离散 | 放一晚等花自己睁开一次。 |
| `lay:` | 离散 | 鸡下一次蛋有冷却（5–10 分钟），不能下半个。 |
| `bucket:` | 离散 | 舀一桶液体是一次动作（`bucket:lava@lake` 一趟舀 10 桶）。 |
| `fill:` | 离散 | 给桶装一次内容物（细雪桶）。 |
| `scoop:` | 离散 | 用桶捞一只生物是一次动作。 |
| `scoop_spawn:` | 离散 | 等一只生物刷出来再捞，不能算半只。 |
| `interact:` | 离散 | 取一次蜂蜜这类交互是一次动作。 |
| `shear:` | 离散 | 剪一只羊一次给 2 个毛，不能剪半只。 |
| `water:` | 离散 | 走到水边装一次水。 |
| `roam:` | 离散 | 在群系里游荡等一次刷怪：产出是概率期望（常见 0.08 件/次），不能只游荡 8%。 |
| `travel:` | 离散 | 跑一趟路程（到达某个结构）是一次事件。 |
| `portal:` | 离散 | 造一次传送门（凑齐 10 块黑曜石并点火），不能造半个。 |
| `end:` | 离散 | 一次末地事件（搭桥横渡、进末地）。 |
| `capability:` | 离散 | 获得一项能力/状态一次。 |
| `cast:` | 离散 | 一次浇铸产出 10 块黑曜石，不能浇 1 块。 |
| `igniter:` | 离散 | 点一次火（点燃传送门/营火），不能点半个。 |
| `kill:` | 离散 | 杀一只：铁傀儡掉 3–5 个铁锭，没有「杀 0.75 只」。 |
| `spawner:` | 离散 | 刷怪笼等一只怪刷出来再杀，一次一只。 |
| `haunt:` | 离散 | 一次闹鬼事件（等待 + 击杀），产出按次结算。 |
| `raid:` | 离散 | 打完整场袭击（多波），不能打半场。 |
| `wither:` | 离散 | 打一次凋灵，一次掉 5–11 朵玫瑰。 |
| `dragon:` | 离散 | 打一次末影龙（实测约 6 分钟），龙死后才生成龙蛋。 |
| `special:` | 离散 | 触发一次特殊事件（幻翼膜 0.5 件/次）。 |
| `craft:` | 可分割 | 合成可反复做、多余产物可留用：一次 4 个木板按每件 1/4 次摊。 |
| `smelt:` | 可分割 | 烧一件=一件，线性。 |
| `transmute:` | 可分割 | 转化一块=一块，线性。 |
| `convert:` | 可分割 | 转换一件，线性。 |
| `wear:` | 离散 | 铁砧磨坏一级：一次调用是「一直修东西到掉级」这个完整事件，12% 概率已折进成本（期望 8.3 次 × 3.31s），产出确定 1 件。 |
| `oxidize:` | 可分割 | 铜氧化一块=一块。注意这是**并行等待**（放 10 块同时等 27 分钟），不是串行重复；当前成本模型仍按单价乘件数，批量偏保守（高估）。 |
| `tool:` | 可分割 | 工具成本是合成路线的标注（`tool:craft:<物品>`），跟着合成线性。 |
| `trade:` | 离散 | 一次交易一单，可能一次给 18 件，不能只买 1/18 单。 |
| `gift:` | 离散 | 一次英雄赠礼。 |
| `cat_gift:` | 离散 | 猫每天早晨送一次。 |
| `bonus:` | 离散 | 出生奖励箱只有一次。 |
| `barter:` | 离散 | 扔一次金锭换一次。 |
| `train:` | 离散 | 把村民养一级是一次。 |
| `fish:` | 离散 | 抛一次竿等咬钩，产出按次结算（常见 0.09–1 件/次）。 |
| `bind:` | 离散 | 跑一趟结构挖容器（陶片罐/箱子/熔炉…）拿模板里放的物品：一次响应一个容器，不能挖半个。 |
